# Photo Directory

Place your photos here!

Example:
1. Copy your photos into this folder:
   - `public/photos/photo1.jpg`
   - `public/photos/photo2.jpg`
   - etc.

2. Open `src/config/birthdayData.js` and set:
   ```javascript
   photos: [
     {
       id: 1,
       title: "Our iconic chaotic moments",
       caption: "...",
       src: "/photos/photo1.jpg",
       ...
     }
   ]
   ```

That's it! They will instantly show up on the website!
