# Birthday Website Design Specification

## Overview
A modern, playful, aesthetic, and interactive 3D birthday celebration website designed for a bestie. Features a pastel claymorphism/glassmorphism design system, 3D interactive Three.js gift box, blow-out candle virtual cake, 3D tilt polaroids (blank placeholders for photos), heart-touching & slightly flirty letters, audio ambience, and custom confetti effects.

## Visual Design System
- **Style**: Soft Pastel Claymorphism + Dreamy Glow.
- **Palette**:
  - Primary Blush: `#FF9EAA`
  - Lavender Accent: `#E8D5FF`
  - Warm Buttercream: `#FFF9F5`
  - Golden Sparkle: `#FFD166`
  - Charcoal Text: `#2D3748` (WCAG AAA compliant)
- **Typography**: Fredoka, Nunito, Caveat.

## Architecture
- React 19 + Vite
- Tailwind CSS
- Three.js (Interactive 3D gift box & particle field)
- Framer Motion (Transitions, accordion letters, spring animations)
- Canvas-Confetti (Custom celebration bursts)
- Lucide-React (Crisp vector icons)
- Web Audio API (Integrated cute ambient lo-fi music synthesizer)
