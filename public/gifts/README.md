# Gift PNG Directory

Place your chocolates, cheat notes, stickers, and gift PNGs here!

Example:
- `public/gifts/item1.png`
- `public/gifts/item2.png`
- `public/gifts/item3.png`
- `public/gifts/item4.png`
- `public/gifts/item5.png`

Then simply set the `src` paths in `src/config/birthdayData.js` under `giftBoxItems`.
